Key terms to know
Token: a small chunk of text (a word or part of a word). Models read and write in tokens.
LLM: a model trained on text, like Claude or GPT.
Transformer: the neural network architecture behind modern LLMs.
Prompt: the input you give the model.
Context window: how much text the model can “see” at once.
Hallucination: when the model confidently makes up wrong information.
Fine-tuning: further training a model on specific data.
RAG (Retrieval-Augmented Generation): giving the model your documents at question time so it answers from them.
Agent: an LLM that can use tools (search, run code) to complete multi-step tasks.
Diffusion model: the type of model behind most image generators.
